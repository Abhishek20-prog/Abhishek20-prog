### 🧠 2. Student Score Predictor — Machine Learning

A beginner-friendly Machine Learning application that predicts student exam scores using a trained Linear Regression model.

**✨ Features**

- 📚 Uses a synthetic dataset of 100 students
- ⏱️ Study hours as a model input
- 📅 Attendance and previous exam scores as inputs
- 😴 Sleep hours as an additional input
- 📈 Predicts an estimated final exam score
- 🌐 Web interface built with Flask, HTML, CSS, and JavaScript

**🛠️ Tech Stack**

`Python` `Pandas` `NumPy` `scikit-learn` `Linear Regression` `Flask` `HTML` `CSS` `JavaScript`

**💡 What I'm Learning**

- Data preprocessing and feature selection
- Training and using a regression model
- Making predictions on unseen data
- Evaluating models using MAE, MSE, and \(R^2\)
- Integrating a trained model into a web application
